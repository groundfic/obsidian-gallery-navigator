# 截圖清單（放這個資料夾，檔名要一致）

README 已經預留好版位，把下面 5 張圖截好、命名放進 `docs/`，README 就會自動顯示。
建議桌機淺色主題、視窗拉寬一點、卡片牆有內容（挑封面漂亮的資料夾）。

| 檔名 | 內容 | 建議尺寸 |
|---|---|---|
| `hero.png` | **主視覺**：整個外掛（左樹＋右卡片牆），挑一個封面好看的資料夾 | 寬 ~1600px、橫幅 |
| `cards.png` | 卡片牆特寫（封面卡、釘選、日期） | 方形或直式皆可 |
| `tree.png` | 左側資料夾樹或標籤樹（展開幾層、有數量） | 直式 |
| `search.png` | 懸浮全文搜尋（Spotlight 風，打幾個字、有結果縮圖） | 橫式 |
| `calendar.png` | 行事曆側欄（月曆＋當日時間軸） | 直式 |

## 小技巧
- 截圖前把 vault 名稱、私人筆記標題避開（或截公開內容的資料夾）
- macOS：`Cmd+Shift+4` 框選截圖
- 想要動態展示：另存一段 `demo.gif`（點資料夾→卡片牆→搜尋），再自己加一行 `![demo](docs/demo.gif)` 到 README
- 圖片壓一下（tinypng 之類）再放，repo 才不會太肥
